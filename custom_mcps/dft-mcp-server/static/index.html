DfT MCP Server

✓ Server is running

This MCP server provides access to Department for Transport NaPTAN transport access point data. Connect via the MCP endpoint at /mcp.

Available Tools

get_transport_coverage Tool

Get public transport access points (bus stops, rail stations, etc.) for a region or locality.

count_access_points Tool

Count transport access points by type in a region, broken down by transport mode.

get_available_data Tool

Discover what regions, transport types, and stop types are available to query.

Resources

dft://schema/transport-access-points Resource

Schema and metadata for NaPTAN transport data including stop type definitions and geographic coverage.

Prompts

transport-accessibility-analysis Prompt

Guided analysis template for comprehensive transport accessibility assessment in any region.

Data Source

Data is sourced from the DfT NaPTAN API (National Public Transport Access Nodes) under the Open Government Licence v3.0.
