DfE MCP Server

✓ Server is running

This MCP server provides access to Department for Education apprenticeship statistics. Connect via the MCP endpoint at /mcp.

Available Tools

search_apprenticeship_data Tool

Query apprenticeship statistics with flexible filters for region, age group, level, and year.

get_available_data Tool

Discover what regions, metrics, and time periods are available to query.

Resources

dfe://schema/apprenticeship-statistics Resource

Schema and metadata for apprenticeship statistics including metric definitions and data quality notes.

Prompts

regional-analysis Prompt

Guided analysis template for comprehensive regional apprenticeship outcomes.

Data Source

Data is sourced from the DfE Education Statistics API under the Open Government Licence v3.0.
